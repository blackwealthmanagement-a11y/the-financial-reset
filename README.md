# The Financial Reset

A Next.js starter website for a credit education and financial wellness business.

## Included
- Responsive landing page
- Client intake portal
- Stripe Checkout API scaffold
- CRM dashboard prototype
- Brand disclaimer and LLC attribution

## Run locally
```bash
npm install
npm run dev
```
Then open http://localhost:3000

## Routes
- `/` Landing page
- `/portal` Client intake
- `/crm` CRM prototype
- `/api/checkout` Stripe checkout endpoint

## Production next steps

3. Create Stripe products and replace the sample price.
4. Connect the intake form to your CRM database and email workflow.
